# 白いきれいっちの追加PNG素材

指定された青い輪郭・白い体・きらきらした目に合わせ、内蔵画像生成ツールで作成した透過PNG。

| ファイル | 内容 |
| --- | --- |
| happy.png | 元気 |
| normal.png | 普通 |
| sad.png | 不調 |
| runaway.png | 涙を浮かべ、ピンクの包みを担ぐ家出ポーズ |

`prompts.json` に生成条件と参照画像を保存。家出ポーズの参照は `references/runaway-pose.png`。
このフォルダは追加のデザイン素材。アプリが表示する表情・行動GIFと静止画の生成元は `../CleaningCharacters/`。
